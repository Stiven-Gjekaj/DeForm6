<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `lpObjectArray` -> an array window | One virtual address out of the file decides where `wTotalObjects * 0x30` bytes are read from. |
| `wTotalObjects` -> a loop bound | A `u16` out of the file decides how many elements are read. |
| `ProcCount` -> a later loop bound and allocation | A `u32` out of the file that plan 02-03 uses to size a walk over four-byte pointers. |
| `lpszObjectName` -> a printed string | A virtual address out of the file becomes text a user reads. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-01 | Denial of service | `ProcCount` at `Object + 0x1C` | high | mitigate | Bound `proc_count * 4` against the real length of the file inside `ObjectTable::walk`, record `ImplausibleCount` at `Recoverable`, and clamp the carried value. Nothing downstream may size an allocation from the raw field. |
| T-02-02 | Denial of service | the object array window | high | mitigate | Each element is narrowed to its own `0x30`-byte `subregion` before any field is read, so a truncated file fails at the element and no read runs past the array into unrelated bytes. |
| T-02-03 | Tampering | `wTotalObjects` as the loop bound | medium | mitigate | `wTotalObjects` is bounded by the array region the same `subregion` call produces. A count that asks for more elements than the region holds fails at the first element outside it. |
| T-02-04 | Spoofing | `lpszObjectName` resolving into unrelated bytes | medium | mitigate | The name is read through `region_at_va` and `cstr` with a `0x104` limit, so an address in no section produces a recoverable defect and an empty name rather than a run into neighbouring data. A test patches the pointer and asserts the defect. |
| T-02-05 | Denial of service | `i * 0x30` and the base plus that product | high | mitigate | Checked multiply and `Off::checked_add`. `AGENTS.md` forbids adding two file-derived offsets with the plus operator, because a `u32` sum wraps and then points back inside the file. |
</threat_model>
