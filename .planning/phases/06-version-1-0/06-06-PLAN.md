    | id | extended regular expression | what it catches |
    |---|---|---|
    | `pct-sign` | `[0-9]+(\.[0-9]+)?[[:space:]]*%` | a figure stated as a share of one hundred |
    | `pct-word` | `[0-9]+[[:space:]]*(per cent\|percent)` | the same figure written as a word |
    | `stmt-fwd` | `recover[a-z]*[^.]{0,40}statement` | a claim of statement recovery |
    | `stmt-rev` | `statement[^.]{0,40}recover[a-z]*` | the same claim, written the other way round |
    | `compilable` | `compilable\|recompilable\|compile.ready` | a claim that the output compiles |
    | `decompile-src` | `decompil[a-z]*[^.]{0,40}(source\|[Bb]asic)` | a claim of source recovery from native code |

    Scan case-insensitively. Report each hit with the source name, the line number
    and the shape identifier.

    **Stage 3, the audited allow list.** Some sentences legitimately hold a
    forbidden shape because they are negations or definitions. `README.md` says
    that the tool does not recover statements, and `AGENTS.md` says the same. Hold
    an explicit list inside the script of the exact sentences that are allowed to
    match, each with a one line comment giving the reason it is on the list. A
    matching line that is on the list is reported as ALLOWED and does not fail. A
    matching line that is not on the list fails, and the failure message states
    that the line must either be rewritten or traced and added to the list on
    purpose. Do not widen a regular expression to make a real sentence pass. The
    list is the place where an exception is recorded, and it is a place a reviewer
    reads.

    **Stage 4, the probe.** For every one of the six shapes, write a copy of each
    source into `$WORK` with one violating line appended, run the same scanner over
    the copy, and require that the shape fires. Print one PASS or FAIL line per
    shape naming the shape identifier and the planted line. If any shape does not
    fire, exit 1 with a message saying the scanner is wrong, not the probe. Six
    shapes across three sources is eighteen planted checks; report the count.

    fail. A fact check that cannot fail is the same defect as a scanner that cannot
    fail.

    exactly what was found and where, and a final line stating what was proved,
    including the count of sources scanned, the count of shapes hunted and the
    count of planted violations that fired.
