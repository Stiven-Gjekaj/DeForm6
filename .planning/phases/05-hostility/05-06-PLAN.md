<objective>
Run a small, deterministic, dependency free mutation sweep over the vendored
corpus inside the normal gate, so a person who runs `cargo test --workspace`
on a machine with no nightly toolchain still exercises the reader with input
no person wrote.

Purpose: the real fuzzer needs nightly, needs a subcommand installed, and runs
out of band. That is the right place for a sixty second coverage guided
campaign. It is the wrong place for the first line of defence. A change that
breaks the reader on a mutated byte should fail on the developer's own machine,
in the same command they already run before every commit, not an hour later in
a scheduled job.

This test is not a second fuzzer and must not try to be. It is a smoke test:
a fixed seed, a fixed iteration count, a fixed mutation rule, and one
assertion, which is that the process is still running at the end.

Output: one test file with no dependency, whose failure message names
everything a person needs to rebuild the exact input, because the input itself
may never be committed.
</objective>
