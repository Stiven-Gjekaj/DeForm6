<objective>
Build the run time robustness corpus: a committed manifest of pinned hashes, a
command that fetches and verifies every entry, and a fetched directory that
never enters the repository.

Purpose: `AGENTS.md` states the rule plainly. A program enters `corpus/` only
if its licence permits redistribution. Everything else is fetched at run time
from a manifest of pinned hashes. Commit the manifest. Never commit the bytes.
The vendored corpus is 44 programs and it is the ground truth set, because
each one ships with the source it was built from. The robustness set is the
opposite: no ground truth, no source, and no licence, but many more shapes of
real Visual Basic 6 executable than 44 programs from two upstreams can offer.

The named risk this plan answers: the corpus can disappear. A pinned hash
proves that the bytes are the bytes, and it says nothing about whether the
address still resolves. A fetch that fails must fail loudly. The natural, easy
shape of a fetch loop skips a failure and continues, and that turns the
robustness set into a set of zero files that passes every check.

Output: the manifest, the fetch command, the pin command that writes an entry
into the manifest, and a refusal for every silence.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| the network to the local file system | Bytes arrive from an address nobody in this repository controls, and a command writes them to disk. |
| the manifest to the destination path | A key in a committed file decides a file name. A key holding a path separator would decide a directory. |
| the fetched set to the repository | These programs carry no licence that permits redistribution. Their bytes must never become a commit. |
