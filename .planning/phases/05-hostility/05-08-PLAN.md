<objective>
Prove the claim this whole phase exists to support: the tool does not panic on
any input. One run, three sources, both modes, a counted report, and no
aborted process.

Purpose: SAF-01 is one sentence and it is the hardest requirement in the
project to prove. The fuzzer gives evidence for it and not a proof, because a
campaign that finds nothing in sixty seconds has looked at a tiny part of the
space. The proof this plan builds is the other half: an exhaustive run over
every input this repository can reach, so the claim rests on a number rather
than on an absence.

`AGENTS.md` names the discipline this plan is measured against twice over.
Measure the thing you tell the human, not something near it: a directory size
is not a state and a count of what a walk found is not a count of what exists.
Give the number you can prove and not a number calculated from a part: three
sources means three counts, each taken where it lives.

Output: one test that reads everything, counts everything, names every source
separately, and says plainly when a source is not there.
</objective>
