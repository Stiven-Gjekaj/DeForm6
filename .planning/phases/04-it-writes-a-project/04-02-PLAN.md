<objective>
Turn one recovered property value into the exact bytes the VB6 IDE writes for
it, and turn one property the reader could not decode into a report item
instead of a line.

Purpose: the reader's type system was built to decode bytes, not to remember
display intent. It knows that `BackColor` is a four byte signed value. It does
not know that the IDE writes that value as eight upper case hex digits between
`&H` and `&` on an intrinsic control and as a plain signed decimal on an
external one. That intent lives only in `FILE-FORMATS.md`, keyed by property
name, and this plan is where it becomes code.

The second reason this plan exists on its own: most property records in this
corpus carry no name and no value. 683 of 805 report present and not decoded.
A formatter designed around the decoded case with an afterthought for the rest
would look correct on a simple form and would quietly write near empty control
blocks for a complex one.

Output: a formatter that produces the measured bytes for every decoded value
shape, and a stated, tested omission path for every value shape it cannot
produce.
</objective>
