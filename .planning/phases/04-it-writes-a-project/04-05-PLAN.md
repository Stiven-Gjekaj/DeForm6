<objective>
Write the module file and the class file the IDE accepts, and write every
procedure the tool recovered as a valid empty procedure with the right
signature, so the project still builds.

Purpose: this requirement is the one that keeps the whole output compilable.
A project whose forms and names are perfect still fails to build if a procedure
that other code calls is not declared. Writing the signature with an empty body
is what lets the IDE open the project, compile it, and show the developer a
real skeleton of the program rather than a list of names.

This plan also owns the two preambles and the code region emitter that the form
writer shares. The class preamble and the form block look alike and are not
alike: different indent, different name pad, different space count. Measuring
both once, in one file, is cheaper than discovering the difference from a load
error.

Output: a module writer, a class writer, a shared attribute block, a shared
code region emitter that the form writer also calls, and a signature formatter
that reproduces every modifier the reader recovered.
</objective>
