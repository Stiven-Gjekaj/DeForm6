<objective>
Close the loop: read every file this phase wrote back through a reader that
shares nothing with the writer, assert the whole structural list the roadmap
names, and pin what the writer emits so a fall fails the build.

Purpose: full recompilation cannot run here. It needs the VB6 IDE on Windows
and this continuous integration has neither. The structural check is what runs
instead, and the honesty of the whole phase depends on it being a real check
and on nobody implying it is the other thing.

The check has one property that matters more than its coverage: it must not
share code with the thing it tests. The harness already owns a second,
independent form file reader, written for exactly this reason two phases ago
and used by the differential gate ever since. This check reuses it against the
written output, which makes a bug shared between the writer and the checker
impossible rather than unlikely.

Output: the structural check over all 44 corpus programs, the resource offset
resolution check, the encoding sweep, the write side pinned numbers, and a
recorded red run for every assertion.
</objective>
