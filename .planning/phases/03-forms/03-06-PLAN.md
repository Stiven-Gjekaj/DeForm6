## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| file to parser | Every opcode, every payload width and every declared length in the property stream comes from the file. |
| table to parser | The opcode table decides the payload width for a named opcode. A user supplied table can name a width the payload does not have. |
| property to property | One payload's width decides where the next opcode is read. A wrong width shifts every property after it in the same block. |
