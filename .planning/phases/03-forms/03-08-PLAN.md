<objective>
Recover the CLSID of a third party control and say plainly what the tool
cannot do with that control's property blob.

Purpose: FRM-04 asks for both halves and the second half matters as much as
the first. The CLSID is recoverable by joining the class name in the form
stream against the external component table phase 2 already walks. The
property blob is the control's own serialisation and interpreting it needs the
control's own type library, which this repository does not hold and has no
right to redistribute. One fixed header inside that blob is readable without
the type library, and this plan reads it.

Output: `crates/deform6/src/vb/ocx.rs`, plus the textual GUID decode on
`Component`, which phase 2 deliberately carried undecoded.
</objective>
