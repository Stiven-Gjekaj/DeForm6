## What this session measured before the plan was written

**Treat every line as a lead, not as a fact.** Take each measurement again and
write your own numbers in the SUMMARY.

**Ground truth.** All three corpus project files that reference this control
declare the same identifier on their own `Object=` line:

    corpus/public-domain/SK-TFTP-Sample__VB6/Client/TFTPClient.vbp
    corpus/public-domain/SK-TFTP-Sample__VB6/Server/Server.vbp
    corpus/public-domain/SK-Winsock-Sample__VB6/SubReality_WinsockSample.vbp

Each reads `Object={248DD890-BB45-11CF-9ABC-0080C7E7B78D}#1.0#0; MSWINSCK.OCX`.
Note the version part is `#1.0#0`. The verification report quotes `#1.1#0`,
which the committed files do not say. Correct that in your own notes.

**The three executables that hold a component entry.** These paths are not the
ones the verification report and plan 03-08 name. The two TFTP programs sit
one directory deeper than those documents state:

    corpus/public-domain/SK-TFTP-Sample__VB6/Client/demo/TFTPClient.exe
    corpus/public-domain/SK-TFTP-Sample__VB6/Server/demo/Server.exe
    corpus/public-domain/SK-Winsock-Sample__VB6/demo/SubReality_WinsockSample.exe

**A whole file search for the declared identifier.** This session searched
each of the three executables for `248DD890-BB45-11CF-9ABC-0080C7E7B78D` in
six forms: the sixteen byte binary layout with the first field in file order,
the same with the first field reversed, upper and lower case plain text, and
upper and lower case sixteen bit text. **It was not found in any executable in
any of the six forms.**

**What was found.** The sixteen byte value `248DD896-BB45-11CF-9ABC-0080C7E7B78D`
is present in all three executables, at file offsets `0x2180`, `0x1738` and
`0x1f18`. That is the value plan 03-08 identified at the entry field named
`oUuid`, at entry offset `0x04`. It differs from the declared identifier in
one byte.

**What this points at.** The compiled executable appears not to hold the
identifier a registry lookup would use for this control. If your own
measurement confirms that, the honest answer is a reported value with a
statement of what it is not, exactly as the human instructed. If your
measurement finds the declared identifier somewhere this session missed, your
measurement wins, and you report which offset it sits at.
