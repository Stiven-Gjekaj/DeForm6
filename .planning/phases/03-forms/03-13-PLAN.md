## The measurement this session already took, and what you do with it

This session measured the four bytes below directly, with a script, before
this plan was written. **Treat every number here as a lead, not as a fact.**
Take each measurement again yourself, in at least two corpus programs, and
write your own numbers in the SUMMARY. If your measurement disagrees with a
number below, your measurement wins and you record the disagreement.

In `corpus/vb6-code/Fire-effect/Fast_Flames.exe`, the form `frmFire` starts
its property stream at file offset `0x138d`, immediately after the `cType`
byte `0x0d` at `0x138c`:

| Offset | Byte | Reads as |
|---|---|---|
| `0x138d` | `01` | opcode 1, then a two byte declared length `0x0039` (57), then 56 characters and a terminating zero at `0x13c9`. The committed `frmFire.frm` gives `Caption = "Even Faster Real-Time Fire Effect - www.tannerhelland.com"`, which is 56 characters. |
| `0x13ca` | `03` | opcode 3, then four bytes `05 00 00 80`. The committed `frmFire.frm` gives `BackColor = &H80000005&`. |
| `0x13cf` | `19` | opcode 25, already handled by `read_special_opcode` as the scale mode case. |
| `0x13d3` | `00` | opcode 0, already handled as a no-output opcode. |
| `0x13d4` | `23` | opcode 35, then a four byte length `0x00000586` (1414) and the blob. The committed `frmFire.frm` gives `Icon = "frmFire.frx":0000`. |

A second, independent sample:
`corpus/public-domain/SK-Winsock-Sample__VB6/demo/SubReality_WinsockSample.exe`
holds the byte `0x23` immediately before an inline blob whose bytes match the
committed `frmMain.frx`, and that form's own `.frm` gives an `Icon` line at
frx offset zero.

## Three hazards the corpus-wide gate will surface

`crates/deform6/tests/differential.rs` already compares every recovered
property against the committed `.frm` value, in both directions, across all
44 programs. Adding a row therefore puts that row on trial immediately. Three
shapes will not compare as plain text, and each needs an honest answer rather
than a suppressed comparison:

1. A colour is written `&H80000005&` in a `.frm` and reads back as a signed
   32 bit value. The two texts differ while the value is identical.
2. A text payload's declared length may count a terminating zero that the
   `.frm` value does not carry.
3. A declared value of the form `"name.frx":OFFSET` or `$"name.frx":OFFSET`
   names a resource file, not a literal. There is no literal on the declared
   side to compare against.

Handle each where the comparison happens, with the reason written next to it.
Never handle one by dropping the property from the comparison silently.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| file to parser | A newly named opcode makes the property loop read further into attacker-controlled bytes than it read before. Every byte past the old stopping point is now parsed. |
| corpus to table | A row measured from two files is asserted for every file. A wrong width silently shifts the cursor for every later property in the block. |
| repository to law | A property table is the one place in this phase where a third party type library would be the easy source. D-01 bars it. |
