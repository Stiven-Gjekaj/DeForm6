## Flagged assumptions carried into this plan

- **`03-RESEARCH.md` A4.** The array index field at offset 0x05 may be one
  byte or the low byte of a two byte field spanning 0x05 and 0x06. No corpus
  index exceeds 24, so the high byte is always zero either way and the corpus
  cannot tell them apart. Task 1 reads two bytes defensively and refuses a
  value the low byte alone cannot hold, per the research recommendation. The
  assumption stays open and this plan says so rather than closing it.
- **`03-RESEARCH.md` Pitfall 1.** The zero children reconciliation and the
  with children case do not obviously follow one formula. Task 2 validates
  against a form with children first, then against a form with none. A tiling
  check that passes on every zero children form and under-consumes on every
  form with a container is the warning sign the research names.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| file to parser | Every scope byte, every control block `Length`, every declared name length and every array index comes from the file and is untrusted. |
| block to block | One control block's `Length` decides where the next one starts. A wrong `Length` moves every later read. The tiling check is the boundary that catches it. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-01 | Denial of Service | The scope byte run in `vb/controltree.rs` | high | mitigate | `MAX_SCOPE_RUN` is the constant 64 and this repository chooses it. A run that reads 65 bytes with no terminating byte refuses and names the byte offset where the run started. The bound is never read from the file. |
| T-03-22 | Denial of Service | A control block whose `Length` is 0 | high | mitigate | A `Length` of 0 does not advance the cursor and would loop. The walk refuses it and names its byte offset. The research measured this exact value appearing when a flat jump ignores the scope run. |
| T-03-02 | Tampering | Every cursor step in the walk | high | mitigate | `Off::checked_add` on a bare `u32` only. `Off` implements no `Add`, so the compiler refuses the unsafe form. `scripts/prove-region-wall.sh` proves the wall holds. |
| T-03-23 | Denial of Service | A declared control name length | high | mitigate | The declared length is checked against the remaining bytes of the block before any subregion is taken. No allocation is sized from it before that check. |
